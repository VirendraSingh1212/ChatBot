# 🔐 Security Policy

## Supported Versions

The following table outlines which versions of the project are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

As this is an early-stage project, only the **latest version (1.0.x)** is actively maintained with security patches. Please update to the latest release to ensure you're protected against known vulnerabilities.

---

## 🛡️ Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in this project, please report it responsibly by following the steps below:

- 📧 **Email**: [singhvirendra0066@gmail.com]
- ⏱️ We aim to respond within **48 hours** of receiving your report.
- 🛠️ If your vulnerability is confirmed, we will work on a fix immediately and keep you updated throughout the process.
- 🔒 **Please do not publicly disclose** the issue until a fix is released and acknowledged.

Your contributions to making this project secure are greatly appreciated!
